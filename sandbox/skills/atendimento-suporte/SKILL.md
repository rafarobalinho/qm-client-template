# Procedimento Padrão de Atendimento (SOP)

Quando o usuário solicitar suporte:
1. Identifique o nome do usuário e a gravidade do incidente (baixa, média, alta).
2. Consulte o histórico de chamados ou execute as ferramentas do sandbox para validar status de serviços.
3. Responda sempre em português claro, cordial e objetivo.
4. Se o incidente envolver falha crítica de sistema, alerte o responsável imediatamente.
